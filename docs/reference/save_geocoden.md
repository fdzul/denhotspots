# Save the geocoded dataset

This function generates the RData file where it contains the geocoded
data and the sinave database.

## Usage

``` r
save_geocoden(x, y, directory, loc)
```

## Arguments

- x:

  is the geocoded data.

- y:

  is the dataset o sinave.

- directory:

  is the folder where the RData file is to be saved

- loc:

  is the name of geocoded name locality

## Value

a RData
